HOW THE INTERNET WORKS

Objective:
To understand how a browser, server, and database interact when a user
requests information from a web application.

Components:
1. Browser - The client application used by the user.
2. Server - Processes the user's request and provides a response.
3. Database - Stores and retrieves the required data.

Process:

1. The user enters a website address or performs an action in the browser.
2. The browser sends an HTTP request to the server.
3. The server receives and processes the request.
4. If data is required, the server sends a query to the database.
5. The database searches for the requested information.
6. The database sends the required data back to the server.
7. The server processes the data and prepares a response.
8. The server sends the response back to the browser.
9. The browser displays the result to the user.

Flow:

User
  |
  v
Browser
  |
  | HTTP Request
  v
Server
  |
  | Database Query
  v
Database
  |
  | Data
  v
Server
  |
  | HTTP Response
  v
Browser
  |
  v
User sees the result

Example:

When a user opens an online shopping website and searches for a product:

Browser -> sends search request -> Server
Server -> requests product information -> Database
Database -> returns product information -> Server
Server -> sends result -> Browser
Browser -> displays the product to the user

Conclusion:

The activity demonstrates how the browser, server, and database work together
to process a user's request and return the required information.
